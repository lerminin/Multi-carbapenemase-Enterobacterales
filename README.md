
This repository accompanies the manuscript: Global genomic epidemiology of multi-carbapenemase Enterobacterales.

Scripts for plots and statistical analysis in R are provided as a Quarto file `code.qmd` with the corresponding rendered HTML file `code.HTML`. Data files required to run the code are included in the `data/` folder.

Note that several figures included in the manuscript (Figure 2 legend, Figure 3) were made or modified with external programs (Inkscape, Cytoscape) and are not included here.
